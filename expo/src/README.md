# src — то, ИЗ ЧЕГО собран зал

Здесь лежит материал, который зал **не открывает во время работы**. Всё, что он
читает по имени, лежит уровнем выше: `assets/photo`, `assets/people`,
`assets/album`, `assets/fonts`, `audio/`, `media/`.

| папка | что внутри | кто читает |
|---|---|---|
| `renders/` | рендеры прилавков и углов | `qa/cut_bench.py`, `qa/cut_corners.py` — режут из них куски в `assets/photo/` |
| `pictures/` | 43 оригинала картинок, уже вшитых в `expo.html` как base64 | `tools/inject_assets.py` — пересобирает из них этот блок |
| `audio/` | пак вушей (192 kbps стерео), сырые mp3, старая помузыкально-эпохальная схема | никто; из пака нарезаны `audio/whoosh/*.m4a` (48 kbps моно) |

Правило простое: **если файл нужен залу в браузере — он не здесь.** Если он
нужен только чтобы этот файл заново изготовить — он здесь.

Папка `Artefacts/` рядом — материал Эльдара, к коду не привязана ничем.
