# src — то, ИЗ ЧЕГО собран зал

Зал **не открывает** отсюда ничего. Всё, что он читает по имени, лежит уровнем
выше: `assets/photo`, `assets/people`, `assets/album`, `assets/fonts`,
`audio/whoosh`, `audio/mus_hall.m4a`, `media/`.

Здесь — материал, из которого это изготовлено:

| что | кто читает | зачем |
|---|---|---|
| рендеры прилавков и углов | `qa/cut_bench.py`, `qa/cut_corners.py` | режут куски в `assets/photo/` |
| 43 картинки-оригинала | `tools/inject_assets.py` | пересобирает блок base64 внутри `expo.html` |
| звук: пак вушей 192 kbps, сырые mp3, старая музыка | никто | из пака нарезаны `audio/whoosh/*.m4a` (48 kbps моно) |

## Раскладывай как угодно

Скрипты **не знают путей внутри `src/`** — они ищут файл по имени, обходя все
вложенные папки. Переименовывай и перекладывай свободно: пока имя файла то же,
всё работает. Не читаются только `src/audio` (там нет картинок зала).

Единственное, чего делать нельзя, — **удалять** отсюда файлы. Зал не сломается
(картинки уже вшиты в `expo.html`), но перевшить их будет не из чего.
`inject_assets.py` это проверяет: если имя не найдено, он называет его и
останавливается, ничего не тронув.

`Restored from expo.html/` — четыре оригинала, которые были потеряны и
восстановлены обратно из вшитого base64 (23 сентября).
