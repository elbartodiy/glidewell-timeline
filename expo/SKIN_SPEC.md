# PHOTO SKIN — производственный манифест
Все ассеты кладутся в `expo/assets/photo/` с точными именами из таблиц.
Движок, механики и аудиты не меняются — меняется только «кожа» в слотах.

## Общие требования к КАЖДОМУ ассету
- **Ровный нейтральный свет.** Без жёстких запечённых теней, бликов и световых пятен —
  конусы ламп, пулы света, виньетку и тёплый градинг кладёт движок поверх,
  и только так свет «едет» правильно при движении камеры.
  Лёгкое ambient occlusion у основания предмета — допустимо.
- **Тайлы** (стены/столешницы/фасады/полы) — строго бесшовные по горизонтали.
- **Стоящие предметы** — фронтальная проекция (из ваших трёх — «фронт»), PNG/WebP с альфой,
  без отброшенной тени.
- **Лежащие предметы** — верхняя проекция (вид сверху), движок сам укладывает её
  на столешницу с ракурсным сжатием.
- Размеры ниже — максимумы; меньше можно. Целимся в суммарный вес до ~60 МБ
  (площадка — офлайн-киоск, это не проблема, но N100 не любит гигантские декоды).

## 6. Порядок внедрения
1. **Пилот**: welcome + эпоха 1 — `wall/bench/floor_e1` + натюрморт welcome.
   Монтируется за флагом `?skin=photo`, старый вид остаётся дефолтом.
2. Сверка с референс-кадром, подгонка температуры лампы и виньетки.
3. Эпохи 2→4 поверхностями, затем рекреации/пьедесталы, затем предметы по битам.
4. Переключение дефолта, старый скин остаётся аварийным флагом `?skin=flat`.
